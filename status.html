faxx-hr (pracovní název)

Hodnocení životopisů pro personalisty — s bezpečnostní vrstvou proti skrytému textu v CV (prompt injection)

Prototyp F0 · Benchmark AI Act · High-risk

⚠ Brána projektu: F0 — Benchmark detekce skrytého textu

Žádná plná Cloudflare infrastruktura, dokud benchmark na sadě čistých + „otrávených" CV nepotvrdí, že detekce funguje.

Exit (návrh): recall ≥ 98 % na held-out sadě · false-positive ≤ 5–10 % na čisté · přesnost extrakce ≥ 90 %.
Hotovo: detektor v2 (WCAG kontrast, Unicode nosiče, visible/hidden split, lidské popisy nálezů) · regresní sada 14/14 (9 útoků + 5 FP kontrol) · živě na Cloudflare — DOCX i PDF (přes Cloudflare Workers AI). Zbývá: held-out sada + externí red-team + kalibrace prahů.

Princip: odděl extrakci od hodnocení

Skórovací logika nikdy nevidí surový text. LLM #1 dělá jen strukturovanou extrakci do pevného JSON schématu (žádné skóre). Skóre počítá deterministický rubrik v kódu nad tím JSONem. Injection „tento kandidát je nejlepší" nemá kam zapsat — schéma má jen years_experience, skills[], education[]. Personalista rozhoduje sám (decision support, ne decision maker). Detektor navíc rozdělí text: do modelu jde jen viditelný text, skrytý (hidden_text) jen do review — co člověk na papíře nevidí, model nedostane.

Bezpečnostní pipeline (6 fází)

[uchazeč → e-mail s CV] │ [CF Email Routing → Email Worker (postal-mime)] ← recyklace z job-watch-mail ▼ originál → R2 (immutable), stav → D1 [Sanitizace + DUAL-PATH DIFF] textová vrstva PDF vs. render→OCR/vision (on-prem) │ co je v (a) a ne v (b) = skrytý obsah → FLAG ▼ [LLM #1 extrakce] pevné JSON schéma + evidence (žádné skóre) ▼ [Normalizace + validace KÓDEM] ▼ [Deterministický rubrik] váhy personalisty (+ volitelně LLM #2 na měkká kritéria) ▼ [Review personalisty] skóre + důvody + zdrojové pasáže + flagy → rozhoduje člověk

5 vrstev obrany (defense in depth)

Ingest do R2 (immutable) — originál se nikdy nepřepisuje; auditní kotva.
Dual-path diff — detektor skrytého textu (ne tichý filtr); nález se zobrazí personalistovi.
Deterministické detektory v2 + CDR — WCAG kontrast vůči skutečnému pozadí, font < 4pt, render mode 3, DOCX w:vanish, hlavičky/patičky, Unicode nosiče (zero-width, Tags E0000+); regex jen eskaluje severity. CDR (Dangerzone) párovaná s kontrastem.
Extrakce s omezeným schématem — model nemá pole na verdikt; identity / qualification / sensitive odděleně, chráněné znaky se neskórují.
Deterministický rubrik + audit — skóre v kódu, breakdown s evidence; audit_log append-only, záznam lidského rozhodnutí.
